# Black-box optimization techniques for modelling new materials

Modern modelling of new materials is increasingly based on computationally expensive finite-element and multiphysics simulations. In such settings, the objective function is often available only as the output of an external solver, while analytical gradients are missing, noisy, or too expensive to obtain. The computational package presented in this implements a practical black-box optimization framework that combines evolutionary search, batch evaluation, caching, and parallel execution for simulation-driven design tasks.

The main contribution of the implementation is an integrated workflow that connects optimization methods directly to finite element packages (COMSOL Multiphyscis, ACELAN-COMPOS) and performs parameter optimization or shape optimization. This dual support is important for new materials modelling, where both constitutive parameters and geometric features can influence final performance.

The core scenario for modelling of new material consists of generating of representative volume geometry, evaluating its response under certain loading conditions, and then optimizing either the material parameters or the shape of the geometry to achieve desired properties. 

Currently we developed robust derivative-free local improvement strategy tailored to expensive external simulations based on multi-start gradient search and a genetic optimization pipeline which includes elite preservation, adaptive tournament selection, mutation rate adaptation, and diversity-aware crossover.

A first notable implemented component is the genetic optimization pipeline for COMSOL models. The system reads parameter bounds and solver settings from configuration files, generates populations of candidate solutions, evaluates them in batches, and stores results in a cache. The genetic optimizer goes beyond a textbook implementation in several ways. It preserves elite individuals, uses adaptive tournament selection, adapts mutation rates when population diversity becomes too low, and introduces diversity-aware crossover. If parents are too similar, the algorithm intentionally generates more distant offspring instead of wasting expensive solver calls on nearly identical candidates. For simulation-based optimization, this is a strong design choice: when each evaluation requires an external numerical run, diversity control is not just elegant, it directly reduces the chance of premature convergence and inefficient spending of computational budget.

A second implemented direction is a multi-start, batch-oriented gradient-like search. Although the code refers to gradient descent, its practical realization is closer to a . The optimizer starts from many random initial points, evaluates them in a single batch, selects the most promising candidates, and then explores coordinated perturbations around them. It also keeps a cache of previously evaluated points and adapts the step speed during the search. This method is especially useful when the objective landscape is irregular, solver calls are noisy, or one wants a more structured local search after a global exploration phase. In the context of new-material modelling, such a strategy can efficiently refine promising regions discovered by broader black-box methods.

The third and perhaps most technically interesting implemented component is the shape optimization workflow based on CMA-ES (Covariance Matrix Adaptation Evolution Strategy). Here the project introduces a complete end-to-end pipeline for mesh-based optimization. It automatically extracts admissible displacement boundaries from the mesh, reads the allowable shift ranges for all design variables, generates optimization coefficients, and then runs CMA-ES in a normalized search space. The optimizer includes weighted recombination, covariance matrix adaptation, cumulative step-size adaptation, evolution paths, and periodic eigen-decomposition of the covariance matrix. In other words, the implementation follows the core ideas that make CMA-ES one of the most effective derivative-free methods for high-dimensional continuous search.

This is a particularly good fit for modelling new materials because shape and structural response often depend on many coupled variables with nonconvex interactions. In such cases, manually tuned local methods are fragile, while simple random search is too slow. CMA-ES provides a principled way to learn promising search directions from previous generations and to adapt the search scale automatically. The implementation further strengthens this idea by integrating batch evaluation: when the fitness object supports batch processing, whole populations can be evaluated together. This reduces overhead and makes the optimizer much more suitable for expensive engineering simulations.

An additional practical innovation is the parallel fitness evaluation for shape optimization. The code launches several independent worker directories, writes separate coefficient and normal files for each evaluation, waits for files to become accessible under Windows file-locking conditions, and runs external optimization commands concurrently. This is a small but important engineering achievement. Many research prototypes look convincing on paper but fail in production because external solver pipelines are fragile, especially on Windows systems with heavy file I/O. Here, the implementation explicitly addresses that issue through isolated working directories and robust file handling. As a result, the framework is not only algorithmically interesting but also operationally realistic.

Another strong aspect is the use of automatic boundary extraction and normalized parameter handling. Instead of relying on manually crafted bounds for every shape variable, the workflow derives displacement limits from preprocessing results and then maps the optimization problem into a normalized domain. This improves robustness, simplifies configuration, and makes the algorithms easier to reuse across different meshes and model instances. For conference audiences interested in practical computational mechanics, this is valuable because it lowers the barrier between a research algorithm and a reproducible engineering workflow.

Overall, the implemented novelty of the project can be summarized in four points. First, it builds a unified black-box optimization environment for expensive finite-element models. Second, it combines several complementary search strategies: adaptive genetic optimization for parameter tuning, multi-start local improvement for refinement, and CMA-ES for high-dimensional shape optimization. Third, it adds engineering features that are crucial in real applications but often absent in academic prototypes, namely batch execution, caching, solver integration, and safe parallelization. Fourth, it organizes the whole process around reproducible working directories and configuration templates, which is essential for iterative studies of new materials.

The value of this work is therefore methodological and practical at the same time. Methodologically, it shows how derivative-free optimization techniques can be combined within a single framework for parameter and shape exploration. Practically, it makes expensive simulation-driven design more feasible by reducing redundant evaluations, exploiting parallel resources, and automating preprocessing and postprocessing steps. For modelling new materials, where objective functions are costly and often opaque, these properties are highly beneficial.

In conclusion, this project demonstrates a mature implementation of black-box optimization techniques for simulation-based material modelling. Its main strength lies not in claiming a brand-new mathematical optimizer, but in delivering a coherent computational framework that makes advanced optimization methods usable for real finite-element and multiphysics workflows. That is exactly the kind of contribution that can accelerate the search for new materials: fewer manual interventions, more robust exploration of design spaces, and better use of every expensive simulation run.
