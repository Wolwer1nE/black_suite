1. В папке data/shapes лежат подкаталоги. В каждом сетка в формате .nas и файл normal.txt. Сетка может быть 2D из треугольников или 3D из тетраэдров. 
2. Формат nas может содержать комментарии, начинающиеся с символа $.
их нужно игнорировать при загрузке сетки.
3. Если строка имеет формат
GRID         278         0.00165 0.00676 0.00429, то это узел и 3 координаты. Координат всегда 3, даже для 2D сетки. Для 2D сетки координата z будет равна нулю.
4. CTRIA3      3432       6    1811    1788    1812, то это треугольник, состоящий из 3 узлов. Число 6 - это номер тела, а 1811, 1788 и 1812 - это номера узлов, которые образуют этот треугольник.
5. CTETRA      3433       6    1811    1788    1812    1789, то это тетраэдр, состоящий из 4 узлов. Число 6 - это номер тела, а 1811, 1788, 1812 и 1789 - это номера узлов, которые образуют этот тетраэдр.
6. Файл normal.txt содержит нормали к поверхности в заданных узлах.
Формат: 38 -4.1300E-07  2.8326E-07 -4.4286E-09 
где 38 - это номер узла, а -4.1300E-07, 2.8326E-07 и -4.4286E-09 - это компоненты вектора нормали в этом узле.
7. Для загрузки сетки нужно прочитать все строки из файла .nas, игнорируя комментарии, и создать структуру данных для хранения узлов и элементов (треугольников или тетраэдров).
8. Для загрузки нормалей нужно прочитать все строки из файла normal.txt и создать структуру данных для хранения нормалей, сопоставив их с соответствующими узлами по их номерам.
9. После загрузки сетки и нормалей можно использовать эти данные для визуализации, важно отметить разные тела разными цветами, используя номер тела, указанный в элементах, и отметить точки, для которых указаны нормали, используя их координаты и векторы нормалей для отображения направления нормали.
У нас есть приложение-сервер на синатре, которое сканирует подходящие папки в data/shapes, загружает сетки и нормали, и предоставляет эти данные через API для клиентского приложения, которое визуализирует эти сетки и нормали должно быть на JS (в папке UI уже есть одна страница, нужна еще одна для визуализации сеток и нормалей). Клиентское приложение должно запрашивать данные с сервера и отображать их, используя разные цвета для разных тел и отображая нормали в виде стрелок или линий, исходящих из узлов.
10. Для визуализации сеток и нормалей на клиентской стороне можно использовать библиотеку для 3D-графики, такую как Three.js. Подключить желательно через CDN, чтобы не нужно было устанавливать дополнительные пакеты.
11. На странице визуализации создать сцену, камеру и рендерер для отображения 3D-графики. Затем, используя данные, полученные от сервера, создать геометрию для треугольников и тетраэдров, а также добавить нормали в виде стрелок или линий.
12. Нужно учесть масштабирование нормалей, они могут быть сильно меньше чем размеры сетки, поэтому может потребоваться масштабировать их для лучшей визуализации.
